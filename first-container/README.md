# Express App for Docker Containerization

This is a simple Express.js application created to demonstrate how to containerize a Node.js app using Docker. The main purpose of this project is to package the app into a Docker container, enabling it to run consistently across different environments.

## Features

- A basic Express.js server.
- Designed to work with Node.js 16, which does not include the Fetch API in its core.

## Why?

This project serves as a learning exercise to understand how to:

1. Build a lightweight Node.js application.
2. Create a Docker container for the app.
3. Ensure portability and compatibility across systems.

## How to Use

1. Clone the repository.
2. Build the Docker image.
3. Run the containerized app anywhere.

Enjoy the flexibility of running your app everywhere, regardless of the underlying system!
